## 文档维护约定

- 新增模块文档：放入对应中文分类文件夹，命名与模块一致，并在本 README 登记。
- 每篇文档必须包含"选型对比"与"运维思考"章节（表格形式）。
- 代码行为变更后同步更新对应文档，`review_log.md` 记录变更过程。
